Projeto desenvolvido para a Atividade 02 da disciplina de Frameworks Front-end.

## Objetivo

Desenvolver uma interface web utilizando Tailwind CSS,
aplicando classes utilitárias para estilização e responsividade.

## Tecnologias

- HTML5
- Tailwind CSS
- Git e GitHub

## Funcionalidades

- Painel de acompanhamento de estudos.
- Cards de disciplinas.
- Indicadores de progresso.
- Layout responsivo para diferentes telas.

## Classes utilizadas

O projeto utiliza mais de 30 classes diferentes do Tailwind CSS,
incluindo classes de cores, tipografia, espaçamentos,
dimensões, bordas, Flexbox, Grid e responsividade.

A lista completa das classes e suas funções está
documentada na tabela deste projeto.
